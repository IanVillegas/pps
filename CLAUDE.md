# DecPat Cloud

Para tareas de interfaz React, sigue la guia compartida:

`.agents/decpat-figma-react.md`

Resumen operativo:

- Mantener la linea visual del Figma de DecPat y del Design System GM.
- Usar `sad-aml-shared` primero cuando exponga el componente requerido.
- Crear componentes locales solo cuando el componente no exista o no este disponible en `sad-aml-shared`.
- Dejar componentes locales provisionales faciles de reemplazar por los oficiales.
- Documentar diferencias contra Figma y validaciones ejecutadas al cerrar cada tarea.
